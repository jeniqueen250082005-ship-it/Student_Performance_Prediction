Student Performance Prediction

Project Overview

This project predicts student performance using Machine Learning techniques.

Machine Learning Algorithms

- Linear Regression
- Decision Tree
- Random Forest

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib

Project Features

- Student performance data analysis
- Model training and testing
- Performance prediction
- Model evaluation
- Confusion Matrix
- ROC Curve
- Actual vs Predicted visualization

Project Files

- "student_prediction.py" – Main Python program
- "student_data.csv" – Student dataset
- "linear_regression_model.pkl" – Linear Regression trained model
- "decision_tree_model.pkl" – Decision Tree trained model
- "random_forest_model.pkl" – Random Forest trained model

Objective

To build and evaluate supervised machine learning models for predicting student performance.

Conclusion

The project demonstrates how different machine learning algorithms can be trained, evaluated, and compared for student performance prediction.
